# 狼人杀 AI 策略库设计

版本：讨论稿 v1。整理日期：2026-10-11。

本文整理已讨论的打法与《狼人杀策略库（详细版）》，作为后续多人数、多角色、多规则板子的策略基础。目标是：每个身份都有可靠的基本判断，在不同剩余人数与资源条件下能选择打法，同时保留稳定的个人风格和有依据的冒险。

当前程序实现的是 6 人局：2 狼、1 预言家、1 女巫、2 平民，无警长、无猎人。第一版已将策略库接入五种行动请求，使用说明见第 16 节；本文中的扩展板子和角色技能仍是设计内容。

## 1. 策略库的组织方式

策略选择使用六类条件：**规则板子、真实角色、剩余人数、可能的阵营人数、可见信息、可用行动资源**。

“剩 5 人”适合作为检索入口，但不足以直接选出最佳打法：1 狼 4 好人与 2 狼 3 好人的风险不同；有解药、带毒女巫、可开枪猎人或无票白痴时，行动后果也不同。

### 1.1 三层策略

| 层次 | 内容 | 用途 |
| --- | --- | --- |
| 共同基础 | 规则理解、事实来源、人数推断、投票与技能后果 | 每个身份都掌握，作为判断依据 |
| 身份打法 | 平民判断、预言家信息经营、女巫用药、猎人开枪、狼队配合 | 根据角色与局势检索 |
| 风格与套路 | 谨慎、主动、隐藏试探；悍跳、倒钩、挡刀等 | 在适用打法中体现差异 |

可靠意味着依据可见信息、理解规则、修正判断并计算后果；允许误判、骗局失败和合法的策略失误。推荐优先级是行动参考，不作为“策略不够优就拒绝输出”的校验规则。

### 1.2 分开保存的内容

| 内容 | 例子 | 地位 |
| --- | --- | --- |
| 已确认事实 | 自己的角色、自己真实查验、公开放逐、自己收到的刀口 | 可以用于确定推断 |
| 玩家声明 | 某人自称预言家、宣称救过人、宣称投给谁 | 只确认声明发生过，内容待判断 |
| 当前判断 | 某人更可能是狼、某预言家暂时可信 | 随新信息修正 |
| 表达与行动计划 | 假跳、隐瞒药量、公开攻击 A 而实际投 B | 服务真实阵营，不升级成事实 |

不在该玩家合法视角内的私有结果、实际药量、真实身份和个人投票，不得作为其检索条件。公开翻牌、合法私有查验或角色揭示获得的信息可以使用。狼队共同计划只能来自规则允许的队内沟通；不直接读取队友个人私有策略。

事实需要保留时间与规则来源。存在阵营转化或变化查验结果的板子中，过去的查验只确认当时得到的结果，不能无条件证明当前阵营。

## 2. 板子规则必须明确

策略卡引用这些条件，而不是默认所有板子都遵循一套“标准规则”。

| 规则项 | 需要明确的值 | 影响 |
| --- | --- | --- |
| 初始配置 | 总人数、各角色数量、阵营结构；哪些配置公开 | 狼数上限、身份占位与排除法 |
| 狼人胜利 | 人数达到好人数、屠边、屠城或其他条件 | 是否必须本轮行动、技能的胜利价值 |
| 好人胜利 | 狼人全灭；第三方存在时的额外要求 | 最后一狼处理与终局判断 |
| 判胜时机 | 夜晚、放逐、开枪、殉情等结算前后；同时达成条件时如何裁决 | 是否还有反击机会 |
| 狼刀 | 是否允许自刀、刀队友、空刀；特殊狼的额外行动 | 银水可信度、平安夜解释 |
| 查验 | 查阵营还是具体身份；特殊角色是否有伪装结果 | 金水的含义与身份排除 |
| 女巫 | 自救限制、用药次数、同夜能否双药、何时能看到刀口 | 救人与毒人选择 |
| 猎人 | 哪些死亡触发枪、是否可弃枪、可选目标、是否允许连锁开枪 | 夜刀、放逐、用毒与威慑 |
| 防护与连锁 | 守护限制、同守同救效果、毒与保护的关系、情侣或魅惑连锁 | 行动后的实际减员 |
| 死亡公开 | 是否翻牌、是否公开死因、名单顺序是否表达死因 | 出局者阵营与夜间来源推断 |
| 投票 | 个人票型是否公开、票权、弃票、自投、平票与复投规则 | 归票、冲票、票数计算 |
| 警长 | 是否存在、票权、发言顺序与警徽处置 | 竞选与查验结果传递 |
| 发言与遗言 | 每日几轮、是否可补充或退水、遗言范围、技能前后发言 | 试探与信息发布窗口 |
| 队内交流 | 狼队何时能沟通、共享哪些内容 | 狼队分工及改票条件 |
| 特殊角色 | 技能、阵营变化、身份可见范围、自爆等是否存在 | 专属卡的可用性 |

未定义的扩展规则先标为未知；依赖该规则的策略不进入推荐。规则应有版本，旧局面的推断不跨规则版本沿用。

### 2.1 当前 6 人规则的适配记录

- 人数胜利：狼人全部出局则好人胜；存活狼人数不少于好人数则狼人胜。当前引擎在夜晚结算后、放逐后检查。
- 狼刀只能选择好人，没有自刀或空刀操作。因此女巫收到的真实刀口是确定好人。
- 女巫可以自救、同夜不能双药；目前即使解药已用完，仍会得到当夜刀口。被刀女巫仍在当夜行动，天亮统一结算。
- 查验得到阵营；死亡与放逐不翻牌，公共票型只有总得票数。
- 每位存活玩家每天一次发言，没有警长、补充发言、遗言、开枪或自爆机制。
- 对外认狼只是声明，不会触发自爆、结束白天或改变技能权限。

## 3. 用人数判断风险

### 3.1 数量与信息范围

| 符号 | 含义 |
| --- | --- |
| N | 当前存活人数，来自公开状态 |
| W、G | 实际存活狼人、好人数；好人通常只掌握候选值 |
| W0 | 公开初始狼数；配置隐藏时使用可见的候选配置 |
| D = G − W | 人数差，只适用于两阵营人数胜利分析 |
| 好人票、狼人票 | 可用票权；可能与人数不同，真实阵营票权对好人也可能未知 |
| 资源 | 自己真实可用技能、公开确认技能，以及他人声称的资源 |

好人维护“仍可能成立的局面”，例如剩 5 人时可能是 1 狼 4 好人或 2 狼 3 好人。硬事实与规则排除不可能局面；主观分析用于比较剩余局面的可信度。不得从引擎全知状态取得准确狼数。

### 3.2 人数胜利规则下的公共约束

以下仅适用于：两阵营、无新增狼人或阵营转化、狼人全灭则好人胜、W ≥ G 则狼人胜、全部待触发技能已处理、已到判胜点且游戏继续。W0 已公开时才使用该确切上限，否则按候选配置分别分析。不能在猎人待开枪等未完成结算期间套用。

| 剩余人数 N | 继续游戏时可能的 W | 判断重点 |
| --- | --- | --- |
| 9 人及以上 | 1 ≤ W ≤ min(W0, floor((N−1)/2)) | 结合原始配置与减员记录；大人数也可能已经濒临判负 |
| 8 人 | 1～3，且不超过 W0 | 3 狼 5 好人与 1 狼 7 好人采取不同节奏 |
| 7 人 | 1～3，且不超过 W0 | 3 狼 4 好人是一次好人减员就到人数线的局面 |
| 6 人 | 1～2，且不超过 W0 | 2 狼 4 好人要计算接下来白天和夜晚的组合减员 |
| 5 人 | 1～2，且不超过 W0 | 2 狼 3 好人错放逐即负；1 狼 4 好人则有较大余量 |
| 4 人 | 恰好 1 狼 3 好人 | 可以排除双狼存活的解释 |
| 3 人 | 恰好 1 狼 2 好人 | 当日投票或阻止下一次狼刀通常是决定性行动 |
| 2 人或 1 人 | 不存在已完成判胜但仍继续的两阵营局面 | 应检查待结算技能、第三方或不同胜利规则 |

这些是公共逻辑约束。若已经确认放逐前是 2 狼 3 好人，放逐一人后仍继续，则被放逐者是狼人：放逐好人会变成 2 狼 2 好人并终局。

### 3.3 行动后果

先完成该板子的技能和连锁，再到规定的判胜点比较结果。若本次结算净减少 ΔG 个好人、ΔW 个狼人，则 D' = D − ΔG + ΔW。

| 人数差 | 无额外技能影响时的含义 | 策略方向 |
| --- | --- | --- |
| D = 1 | 放逐一个好人，或夜刀一个好人，就到人数线 | 好人重视当轮集中行动；狼人寻找立即兑现机会 |
| D = 2 | 错放逐好人后再成功刀好人，会到人数线 | 好人同时考虑下一夜的救、毒、守、枪；不能只看眼前一票 |
| D ≥ 3 | 通常有更多观察余量 | 可以探索信息，但仍检查特殊技能、票权和屠边风险 |

“追轮次”在策略卡中应写成具体结果，如“成功毒狼后从 2 狼 3 好人变为 1 狼 2 好人”，避免只用口号。

### 3.4 屠边、屠城与第三方

- 屠边局同时维护存活平民和神职的候选人数，以及哪一边接近清空。狼数较少也可能通过刀最后一张目标牌取胜。
- 屠城局按规则判断全部好人是否死亡；人数相等不自动终局。
- 无票白痴、警长、多票或禁票效果改变票权，不能用“好人数更多”代替票数分析。
- 情侣、魅惑与其他连锁必须展开后计算。涉及阵营变化时，不能继续使用固定二阵营排除式。
- 第三方角色使用独立目标与结算规则；普通狼队或好人策略只有在适配其真实胜利目标时才可复用。

### 3.5 狼数与资源不确定时怎样选择

1. 先淘汰与硬事实或规则矛盾的局面，不强行填满一个确定狼坑。
2. 对剩余局面标明依据与可信程度；他人声称有药、枪或守护，保留真假两种可能。
3. 寻找在多个可信分支中都有收益的行动，例如保护确定好人、纠正真实信息冲突、减少对可信目标的分票。
4. 有明显取舍时，比较立即判负风险、命中收益、失败代价与下一轮信息机会。低可信的极端分支不自动压过所有已有证据。
5. 若在高可信局面中等待必输，而行动仍有取胜机会，提高行动优先级；说明不确定性，仍选择当前依据最好的目标。

未校准前不要求模型编造精确胜率百分比；使用可解释的局面分支和定性可信度即可。

## 4. 所有身份共用的判断卡

| 卡号 | 打法 | 触发与行动 | 修正或退出 |
| --- | --- | --- | --- |
| C01 | 事实与声明分离 | 将查验、救人、投票声明按来源记录，使用真正可见的事件核对 | 新硬事实出现时重算；自己的假查验仍只是说辞 |
| C02 | 比较多种解释 | 为不同预言家、女巫声明建立条件局面，检查能否解释已知事实 | 不因说法复杂就加分；无法兼容硬事实的解释淘汰 |
| C03 | 评估分票风险 | 使用公开站边与投票意向估计可能票数，并标注未知票 | 实际投票未公开前，不声称知道他人已投哪一票 |
| C04 | 按证据改判断 | 新信息改变原判断时说明具体原因，允许公开改口 | 不为维持一致性固守已失效判断 |
| C05 | 检查人数危险 | 比较错放逐、平票、狼刀、技能命中的分支 | 规则或候选狼数变化后重新评估 |
| C06 | 反套路 | 检查倒钩、互踩、集体带票、假金水是否也能解释行为 | 站对一次边、投过一次狼、互相攻击均不自动认证身份 |
| C07 | 信息披露 | 判断公开信息对投票的收益、暴露技能角色的代价与最后发布窗口 | 即将出局或危险增加时提高披露优先级 |
| C08 | 保留历史 | 记录身份声明、验人声明、站边变化、真实可见的票型 | 不以他人转述替代原话；出局者历史继续保留 |
| C09 | 文字依据 | 引用实际存在的发言与公开行为；按规则要求引用编号 | 语气是弱线索，不凭空补充眼神、动作或未轮到者的沉默 |

实际个人票型公开时，可分析投票与声明是否一致；仅有总票数时，可分析票数约束与公开意向，不能直接指认某人的真实投票。即使公开投过狼，也要考虑卖队友与不得已投票。

## 5. 平民策略库

目标：比较可信解释、贡献可用判断，并让好人的票在关键轮次发挥作用。自己是好人不代表自己的推理必然正确。

### 5.1 按剩余人数选择

| N | 优先参考 | 具体选择 | 切换条件 |
| --- | --- | --- | --- |
| ≥9 | 建立信息结构 | 记录身份与验人声明，比较不同解释；提出一两个能区分解释的问题 | 若接近人数线或屠边线，立即提高归票优先级 |
| 7～8 | 形成可修正站边 | 结合已有信息选暂定阵营线，识别被多人推动的放逐对象；检查最多狼数分支 | 出现可靠反证、关键技能信息或高分票风险时改站边 |
| 6 | 判断下一夜 | 比较放逐候选及其后续减员；避免仅凭存在感低就推出一个人 | 多狼分支成立且错误放逐会导致危险夜晚时，收紧目标选择 |
| 5 | 区分一狼与两狼 | 在 2 狼 3 好人分支中优先形成正确集中票；一狼分支中检查隐藏狼和倒钩 | 规则推断排除某分支后调整风险偏好 |
| 4 | 排除与反倒钩 | 人数局确认仅一狼；比较三名其他玩家，重审此前“站对边”的人 | 新信息确认好人后缩小候选，避免重新怀疑确定好人 |
| 3 | 最终选择 | 人数局确认一狼；在其余两人中选目标，争取另一好人同票 | 对平票和夜晚防护有明确计划时才考虑等待 |
| ≤2 | 规则专用残局 | 仅在其他胜利规则或待结算场景下启用，分析票权、保护与第三方关系 | 到判胜点后按规则终局，不套用普通三人决赛逻辑 |

### 5.2 专属打法卡

| 卡号 | 打法 | 行动与适用条件 | 代价与退出 |
| --- | --- | --- | --- |
| V01 | 有内容的表水 | 交代自己依据、暂定目标和什么信息会改判断 | 自称好人不构成自证；避免占满发言却不给行动方向 |
| V02 | 双预言家比较 | 对照验人时间线、结果和已知事实，给出条件站边 | 真预言家不一定语气更稳；对跳也可能包含好人试探 |
| V03 | 被假查杀回应 | 依据自己的真实身份指出查杀声明为假，解释判断与准备投票目标 | 假声明不直接证明其为狼，继续结合整体局面 |
| V04 | 关键归票 | 在目标较可信且分票危险时推动集中票 | 若主导者与硬事实冲突，停止跟随并提出替代目标 |
| V05 | 掩护与挡刀 | 在保护关键技能能提高阵营胜算时隐去平民身份或穿衣服 | 自己减员也影响胜负；避开会诱使女巫误毒或造成错误归票的说辞 |
| V06 | 假跳试探 | 有明确试探对象、回收窗口及撤回计划时使用 | 单次发言、无遗言或 D=1 时显著降低优先级；下一天不一定存在 |
| V07 | 反倒钩排除 | 重审被保、站对边、踩过狼的玩家是否始终推动阵营收益 | 避免为了“找深水”推翻已确认阵营信息 |

## 6. 预言家策略库

目标：选择能改变局面的查验，及时把真实信息传递给好人，推动正确行动。查到好人同样可以缩小候选并建立合作。

### 6.1 按剩余人数选择

| N | 优先参考 | 具体选择 | 切换条件 |
| --- | --- | --- | --- |
| ≥9 | 信息探索与发布窗口 | 无历史时从未知对象公平选择；有历史时查对不同结果都能改变行动的人 | 小配置、多狼或屠边危险时提前披露，不因人数多就固定隐藏 |
| 7～8 | 查关键分歧 | 查左右站边的未知玩家，或能拆解两套身份解释的对象；发布已有有效信息 | 对跳、本人或金水被推、下一夜生存机会降低时转主动带队 |
| 6 | 当轮兑现 | 提高发布真实查杀、保护真实金水与集中投票的优先级 | 若结果不足以定票，清楚区分真实查验与推测狼坑 |
| 5 | 信息与票数结合 | 两狼分支下尤其重视当日正确放逐；比较查杀目标和可争取的好人票 | 缺乏下一轮机会时，不把披露拖到下一天 |
| 4 | 一狼定位 | 人数局排除双狼，结合真实结果缩小剩余候选；夜验有区分力的未知对象 | 排除后已唯一定位时，行动优先于重复验证 |
| 3 | 最终信息与说服 | 用已有真实结果或严密排除指出最后一狼，争取另一好人同票 | 没有确定结果时保留不确定性，仍作出当前选择 |
| ≤2 | 特殊规则处理 | 使用已取得的结果参与屠城、第三方或技能连锁局面 | 不假设还一定有夜验或白天发布机会 |

### 6.2 专属打法卡

| 卡号 | 打法 | 行动与适用条件 | 代价与退出 |
| --- | --- | --- | --- |
| S01 | 首夜公平探索 | 没有行为信息时，选择合法未知对象，可用局内随机方式打破平局 | 不依据姓名、人类/AI标签或未提供的上局记忆定狼 |
| S02 | 关键查验 | 比较“验好”和“验狼”分别能改变什么；兼顾结果传播机会 | 高嫌疑不是唯一优先级；阵营固定、查验稳定时已确认对象通常无需重复查 |
| S03 | 查杀带队 | 报真实天数、目标与阵营结果，推动当轮处理 | 真查杀与其他推测分开，不把反对者一并定狼 |
| S04 | 金水合作 | 在合适时机提供好人结果，争取协作和集中票 | 真实金水可判断错误；对外金水声明的可信度仍依赖发言者 |
| S05 | 对跳回应 | 维护真实结果，指出对方具体声明冲突，回应摇摆好人的疑问 | 对跳者可能是好人穿衣服；对方被真实验好时不继续当狼处理 |
| S06 | 暂时隐藏 | 无必须公布的信息，且隐藏能提高后续信息收益时使用 | 本人/金水被推、查杀出现、危险增加或最后发言窗口到来时退出 |
| S07 | 信息遗产 | 允许遗言时重述已有真实结果；有警徽机制时使用板子支持的传递规则 | 未来查验计划不是已发生结果；死亡后无法发布的结果不能靠意向补齐 |

有警长时另启用竞选与警徽流卡；没有警长时采用“真实结果、简短理由、当前目标”的发言组织。警徽流的具体解码依赖查验与死亡时序，不能预设所有死亡都完成了下一次查验。

## 7. 女巫策略库

目标：管理救人与击杀资源，结合自己真实获得的信息提高阵营生存和获胜机会。毒药是进攻资源，不是额外一条生命；有毒也不意味着拥有额外投票权。

### 7.1 按剩余人数选择

| N | 优先参考 | 具体选择 | 切换条件 |
| --- | --- | --- | --- |
| ≥9 | 首夜保人、资源经营 | 无行为信息时通常提高救人优先级；未知目标的盲毒收益与风险一起比较 | 已有可靠狼信息、屠边危险或特殊连锁时使用相应专用卡 |
| 7～8 | 可信信息与用药收益 | 比较救信息核心、毒高度可疑对象和保留资源；检查 3 狼等危险分支 | 高可信危险分支中不用药会立即输时，提高行动优先级 |
| 6 | 计算两轮减员 | 检查白天错放逐后下一夜的救、毒、守和枪，避免默认“还能等” | 药量、死亡和狼数解释变化时重新计算 |
| 5 | 一狼/两狼分支 | 2 狼 3 好人时，救人可阻止刀口减员，毒中狼可改变人数；误毒可能直接输 | 有解药时比较保命与毒狼，不一律要求冒险毒 |
| 4 | 防止双重好人减员 | 人数局为 1 狼 3 好人；不用药且仅刀一好人后仍是 1 狼 2 好人，误毒另一好人则可能到 1 狼 1 好人 | 对最后一狼有强依据时提高直接取胜用毒优先级 |
| 3 | 必须行动的夜晚 | 人数局为 1 狼 2 好人；无其他防护时，救刀口或毒最后一狼才能阻止次晨判负 | 自救限制、可用药和其他真实防护改变可选分支 |
| ≤2 | 技能时序专用 | 只在待结算或其他胜利规则中讨论用药，严格判断行动窗口是否仍存在 | 已终局时没有继续用药的机会 |

### 7.2 专属打法卡

| 卡号 | 打法 | 行动与适用条件 | 代价与退出 |
| --- | --- | --- | --- |
| W01 | 首夜救人 | 无可靠行为信息时，救人通常保留更多好人和白天票 | 结合自刀、保护冲突、首夜禁救等规则调整；不是跨板子绝对命令 |
| W02 | 自救保行动 | 被刀且可自救时比较自救后的行动价值 | 放弃自救通常意味着当夜死亡，不能声称把药留到自己以后的夜晚 |
| W03 | 有依据用毒 | 比较真实信息、可信声明和行为；检查命中与误伤后果 | 对跳、自称狼、语气强势不单独构成确定狼信息 |
| W04 | 危急用毒 | 在无可用救人与防护、等待会输的可信局面中选择最有依据的目标 | 风险增加可降低行动门槛；仍不把猜测写成确定身份 |
| W05 | 刀口信息经营 | 不允许自刀时将真实刀口排除出狼候选；允许自刀时仅作证据 | 不能把玩家自称银水当作自己的私有刀口记录 |
| W06 | 披露纠偏 | 银水被假查杀、自己被错误推动或好人缺信息时披露必要记录 | 公开可信度仍需要争取；可选择隐瞒药量，不伪造公开事件 |
| W07 | 最后反击 | 当规则允许被刀后当夜用毒，且无法自救时比较最后行动 | 毒掉最后一狼能否取胜取决于完整结算和判胜顺序 |

### 7.3 用药分支参考

以下采用两阵营人数胜利、同夜不能双药、成功狼刀一名好人、无其他保护或连锁、夜晚全部结算后判胜。W/G 是分析分支，好人未必知道真实值。

| 夜前局面 | 不用药 | 救刀口 | 毒中一狼 | 毒错另一好人 |
| --- | --- | --- | --- | --- |
| 2 狼 3 好人 | 2 狼 2 好人，狼胜 | 2 狼 3 好人，继续 | 1 狼 2 好人，继续 | 2 狼 1 好人，狼胜 |
| 1 狼 3 好人 | 1 狼 2 好人，继续 | 1 狼 3 好人，继续 | 0 狼 2 好人，好人胜 | 1 狼 1 好人，狼胜 |
| 1 狼 2 好人 | 1 狼 1 好人，狼胜 | 1 狼 2 好人，继续 | 0 狼 1 好人，好人胜 | 1 狼 0 好人，狼胜 |

若毒药目标就是刀口，本次死亡人数不会因此增加，但浪费毒药且失去救人机会。若有猎人、守卫或连锁，上表应按具体规则重算。

## 8. 猎人策略库

目标：通过可能的反击、开枪与公开表达影响阵营收益。猎人身份声明不是生前自动自证；枪能否使用由真实技能与死亡条件决定。

### 8.1 先确定规则

- 哪些死亡可开枪：狼刀、放逐、毒杀、自爆带走、魅惑、殉情等分别配置。
- 是否可弃枪，枪的目标范围，是否能触发其他猎人或情侣连锁。
- 开枪前后是否有遗言，是否公开身份，枪与胜负检查的先后顺序。
- 狼队是否存在能绕开枪的击杀方式；守护与救人是否保留猎人的后续行动。

文档或民间口诀不能替代这些定义。特别是“人数已相等但猎人还没开枪”的情形，必须由规则决定是否仍有技能窗口。

### 8.2 按剩余人数选择

此处 N 指选择策略时的公开人数；猎人死亡待开枪时，需另记录死亡后、开枪前的存活人数，避免把两种时点混用。

| N | 优先参考 | 具体选择 | 切换条件 |
| --- | --- | --- | --- |
| ≥9 | 隐藏与正常分析 | 以好人视角参与判断，降低被绕枪技能针对的概率；无信息且可弃枪时审慎评估盲枪 | 本人将被错误放逐、必须公开纠偏或枪有明确收益时提高披露优先级 |
| 7～8 | 威慑与反击目标 | 评估公开身份能否改善归票；建立可修正的枪口候选 | 对跳、绕枪危险和多狼临界分支变化时调整 |
| 6 | 计算放逐后反击 | 比较出狼、误出自己再开枪、误伤另一好人的完整分支 | 不因能开枪就主动接受无收益的放逐 |
| 5 | 关键身份与枪口 | 两狼分支下，先确认误放逐后是否还有开枪窗口，再评估能否追击一狼 | 若胜负先判定，不能依赖终局后的枪追回 |
| 4 | 一狼目标审查 | 人数局仅一狼，使用可信结果和排除法；可弃枪时比较保留好人票与猜枪 | 已高度定位最后一狼时提高开枪优先级 |
| 3 | 决定性反击 | 争取正确投票；死亡时按开枪前人数和规则选择目标，不预设自己一定能逆转 | 被毒或特殊击杀禁枪时，提前提高白天披露和纠偏优先级 |
| ≤2 | 待开枪或特殊残局 | 依规则计算最后一枪、连锁和判胜；可能是普通人数表无法描述的过渡状态 | 仅在技能窗口真实存在时推荐枪击行动 |

### 8.3 专属打法卡

| 卡号 | 打法 | 行动与适用条件 | 代价与退出 |
| --- | --- | --- | --- |
| H01 | 藏枪 | 没有必须披露的冲突，且隐藏能保留有效反击时采用 | 面临绕枪处决、错误归票或最后信息窗口时退出 |
| H02 | 亮身份纠偏 | 被假查杀、误归票或好人缺可信带队者时说明真实身份与枪口依据 | 生前不能靠自称猎人完成身份认证；对跳者也可能是好人掩护 |
| H03 | 有依据开枪 | 优先真实可确定狼或证据最强目标，结合命中和误伤后的结算 | 已确认好人不因情绪或站边分歧成为默认枪口 |
| H04 | 无信息弃枪 | 规则允许，且盲枪可能造成更大阵营损失时比较弃枪 | 等待必输或有明确取胜目标时重新评估，不固定“首夜必闷枪” |
| H05 | 枪口威慑 | 用可执行的公开枪口计划影响狼刀、归票，保留随信息更新的余地 | 可能诱使绕枪击杀；威胁也可能让真正好人不敢给出分析 |
| H06 | 诱刀与掩护 | 被正常刀能有效反击且能保护更重要资源时，提高自己的刀口吸引力 | 被刀不能开枪、屠边风险、无可靠枪口时降低优先级 |
| H07 | 最后信息 | 在允许的遗言或技能前发言窗口交代已有判断 | 不假设每种死亡都有遗言，不把遗言安排当作额外正常发言 |

## 9. 狼人策略库

目标：依据真实阵营胜利条件影响放逐、夜间减员和信息传播。狼人通常知道队友及普通两阵营中的非狼，但对好人具体角色、药量、枪与守护目标仍需推断。

悍跳、冲锋、倒钩、深水是可切换的战术分工，不是新增真实角色，也没有固定高低排名。

### 9.1 按剩余人数选择

| N | 优先参考 | 具体选择 | 切换条件 |
| --- | --- | --- | --- |
| ≥9 | 分工与可信视角 | 协调是否悍跳、谁配合、谁保留；规划刀口和可维持的声明 | 已有接近屠边或人数胜利机会时提高兑现优先级 |
| 7～8 | 争取关键票 | 精确计算本方票、可争取的好人票和最高票规则；避免所有狼同时暴露同一保护关系 | 假预言家失去可信度或队友受到查杀时调整分工 |
| 6 | 夜刀与白天联动 | 两狼时比较错放逐加夜刀能否取胜；一狼时经营单人可信身份 | 女巫毒、猎人枪或守卫防护改变终局分支时调整刀口 |
| 5 | 区分双狼和独狼 | 2 狼 3 好人时集中票推动错误放逐，或评估平票后的夜晚；1 狼 4 好人时避免无收益暴露 | 目标票数不足、反击资源仍在或假声明被反证时换目标 |
| 4 | 独狼对抗 | 人数局仅剩一狼，争取一张关键好人票，保留可被误放逐的目标 | 不再使用保护存活狼队友的计划；死队友历史可用于解释 |
| 3 | 取胜兑现 | 人数局为一狼两好人，集中说服其中一人误投另一人；评估平票后的防护和反击 | 另一好人持可用解药、毒、枪等时不把夜晚视作自动胜利 |
| ≤2 | 完整结算与其他胜利条件 | 检查待开枪、连锁、屠城或第三方博弈 | 已到终局不再推荐补充行动 |

### 9.2 专属打法卡

| 卡号 | 打法 | 行动与适用条件 | 代价与退出 |
| --- | --- | --- | --- |
| L01 | 悍跳 | 选择假结果与时间线，争取投票解释权；给好人假金水可争取支持，给队友假金水可保护队友 | 避免与已知刀口、公开硬事实冲突；结果被推翻时评估调整或撤回 |
| L02 | 冲锋 | 本方集中票加可争取票能影响结果时明确支持队友、推动好人出局 | 少狼不是禁用理由；队友方案明显失败时避免连带暴露 |
| L03 | 倒钩 | 认可真信息，建立信任并为后续错误放逐留空间 | 一直帮好人排尽狼会损害胜利目标；需要兑现信用的机会 |
| L04 | 深水 | 用正常的闭眼视角分析维持低曝光，减少无依据的确定语气 | 关键轮次仍需行动；单纯长期模糊容易成为默认放逐对象 |
| L05 | 互踩与切割 | 适度制造分歧，或在队友难以保住时保留另一狼生存机会 | 不翻牌时卖狼未必有认证收益；两狼局失去队友的成本高 |
| L06 | 制造分票 | 放大已存在的判断差异，选择能形成最高票或有利平票的目标 | 不凭空编造行为；好人形成一致票或复投规则不利时改变方案 |
| L07 | 刀口选择 | 比较信息威胁、技能资源、救守概率、猎人反击与白天误放逐价值 | 被刀女巫仍可当夜用药；正常刀猎人可能带走狼 |
| L08 | 残局冲票 | 一次错误放逐能取胜时，提高集中行动优先级，必要时承担暴露风险 | 技能连锁或判胜时机使计划无法立即兑现时重新计算 |
| L09 | 公共视角经营 | 真实内幕用于内部目标选择，公开理由使用可见信息或自身策略性声明 | 不把自己知道别人是好人直接包装成不存在的公开证据 |
| L10 | 自爆与特殊行动 | 仅在板子存在可调用技能、触发时机和收益明确时使用 | 普通认狼声明不产生自爆能力；是否吞信息依赖具体流程 |

### 9.3 两狼及多狼的共同计划

| 组合 | 适用局势 | 改变计划的信号 |
| --- | --- | --- |
| 悍跳 + 冲锋 | 假预言家有机会获取足够票或错误放逐 | 关键好人公开转边、可靠反证出现、集中票不可兑现 |
| 悍跳 + 倒钩 | 需要在两条身份解释中都保留影响力 | 悍跳一侧失势；倒钩一侧已获得可转化的信用 |
| 双潜伏 | 好人已有分歧，主动曝光收益低 | 队友受查杀、出现立即取胜机会、好人开始完整排除 |
| 切割 + 留存 | 队友难以存活，另一狼仍有独立胜利路线 | 卖队友无法获得信用，或继续保队友仍有足够票 |
| 多狼分工 | 三狼以上且沟通机制允许 | 不机械安排四种岗位；随实际狼数、发言顺序与候选目标调整 |

共同计划至少包含：本轮目标、各自公开立场、预定实际票、可接受的切割程度、公开变化下的改票条件、夜刀备选及关键技能风险。只有规则允许沟通的时机才能同步新计划；投票中看不到他人票时不能临时按已投票结果协调。

## 10. 其他角色的扩展策略

以下角色也按相同人数入口整理；加入板子时必须先匹配真实规则。白狼王、狼美人同时继承适用的普通狼人卡；丘比特和情侣按自己的真实胜利目标选择可复用的共同卡。

### 10.1 守卫

先明确：是否允许空守、自守、连续守同人；守护能否挡毒、特殊狼击杀及连锁；同守同救是叠加、抵消还是致死。守护只证明自己的行动，是否实际挡刀需要可见结果或可靠规则推断。

| N | 优先选择 | 修正条件 |
| --- | --- | --- |
| ≥9 | 比较首夜空守与守人，观察谁能提供关键技能或信息 | 同守同救无冲突时，不能照搬“首夜必须空守” |
| 7～8 | 在信息核心、自守和高概率刀口之间选择，检查连续守护限制 | 多狼或屠边危险提高阻止关键减员的优先级 |
| 6 | 计算接下来一刀的后果，避免只重复“预言家、自守”固定轮换 | 当前信息核心不可信、身份类别濒危或本人被针对时改目标 |
| 5 | 评估 2 狼 3 好人和 1 狼 4 好人分支，保护能延续游戏或保留决定性技能的人 | 已知女巫救人计划只在真实可见或合法沟通范围内使用 |
| 4 | 人数局仅一狼，判断其最有价值刀口；评估守神职与保留好人票 | 根据连守限制和夜刀历史改变预测，避免可被机械猜中的固定顺序 |
| 3 | 人数局需要防止关键好人死亡，结合自守、禁连守与其他防护选目标 | 没有合法有效守护目标时，不虚构能保出下一天的方案 |
| ≤2 | 只在其他胜利规则或特殊技能窗口下比较最后守护 | 判胜已经完成时不能补守 |

| 卡号 | 打法 | 条件、行动与退出 |
| --- | --- | --- |
| GU01 | 预测刀口 | 根据狼队收益和公开信息预测；自己的守人计划不自动等于狼刀目标，预测落空后修正 |
| GU02 | 防护协调 | 有真实冲突规则和交流窗口时与女巫协调；不假定双方读到彼此私有决策 |

| GU04 | 守护诱导 | 公开暗示或误导刀口可能提高守中概率；暴露自身和被绕开的风险超过收益时退出 |

### 10.2 白痴及免放逐角色

不同免死角色不能共用未经适配的技能定义。这里以“首次被放逐可翻牌免死、继续发言但失去投票权”的白痴为参考，具体的次数、公开身份、屠边分类和其他死亡效果由板子决定。

| N | 优先选择 | 修正条件 |
| --- | --- | --- |
| ≥9 | 正常分析与表水，保留票权；隐藏技能是否有利要看特殊狼和胜利条件 | 面临无法纠偏的错误放逐时比较亮身份与触发技能 |
| 7～8 | 评估翻牌信息、白天放逐机会和失票代价 | 不把消耗好人的放逐轮次一律当作浪费狼队资源 |
| 6 | 检查失票后好人能否仍形成足够最高票 | 自己已经翻牌时提高信息组织作用，停止把自己计入可投票者 |
| 5 | 两狼分支下尤其比较实际阵营票权；避免为自证主动丢掉关键票 | 若技能能阻止本次放逐直接判负，则按真实触发顺序使用 |
| 4 | 人数局仅一狼，保留或争取好人集中票；翻牌后协助剩余投票者判断 | 身份已公开且属规则确认时无需重复表水，重点贡献目标判断 |
| 3 | 一狼两好人人数不代表好人有两票；失票会明显改变最高票与平票分支 | 无票时依赖说服、夜间防护和合法技能，而非不存在的自己一票 |
| ≤2 | 在屠边、屠城等规则中检查自身角色分类、免死资源及夜刀 | 已用免放逐技能不能据此防狼刀，除非另有明确能力 |

| 卡号 | 打法 | 条件、行动与退出 |
| --- | --- | --- |
| ID01 | 保留票权 | 在可正常表水与投票时维护好人有效票；不以“我不怕出”主动制造无收益的放逐 |
| ID02 | 翻牌纠偏 | 真正触发且公开认证后，用确定身份提供可信阵营支点；可信身份不保证其推理正确 |

| ID04 | 无票组织 | 准确计算剩余票权，推动仍可投票的好人行动；不把自己的公开意向当作真实投票 |

### 10.3 白狼王及带走型狼人

先区分白狼王自爆带走、狼王死亡开枪等不同触发条件。此处参考“白天允许自爆并带走一人”的白狼王；被放逐是否能带人、是否中断发言、是否禁猎人枪及是否立即转夜均需要明确。

| N | 优先选择 | 修正条件 |
| --- | --- | --- |
| ≥9 | 模仿好人视角隐藏，推断关键目标，比较立即爆破与保留技能 | 明确信息核心或屠边目标出现时提高爆破优先级 |
| 7～8 | 比较去除信息、票权和防护的收益，以及自身减少一狼的成本 | 不能仅因自己受怀疑就默认自爆最优 |
| 6 | 计算自爆双方减员后及下一夜的局面，协调剩余狼队计划 | 特殊角色反击、判胜先后或没有合法窗口时重算 |
| 5 | 两狼时比较交换关键好人与保留两张狼票；独狼时检查自爆后是否已无狼 | 不依赖“只要带人就赚”的固定判断 |
| 4 | 人数局通常只剩自己一狼；自爆可能先使狼全灭，收益必须按完整规则计算 | 只有规则允许的连锁或目标胜利分支能成立时才启用取胜自爆卡 |
| 3 | 优先比较普通误放逐路线与特殊技能路线 | 不把带走一名好人自动等同狼胜，检查自爆导致的狼全灭 |
| ≤2 | 使用特殊技能与多目标同时胜利的明确裁决 | 行动窗口或本阵营胜利条件已不成立时退出 |

| 卡号 | 打法 | 条件、行动与退出 |
| --- | --- | --- |
| WK01 | 关键目标爆破 | 比较信息、有效票、毒药、守护和屠边目标；目标身份仍需依据可见信息推断 |
| WK02 | 中断信息 | 仅在真实技能允许于该阶段中断时使用；普通认狼不能吞发言或警徽 |
| WK03 | 保留特殊狼 | 在尚未出现足够收益目标时采用普通狼打法；受到真实查杀后重新评估窗口 |
| WK04 | 终局交换 | 展开自爆、带走、枪和其他连锁后按规则判胜；剩最后一狼时尤其检查狼全灭优先级 |

### 10.4 狼美人及连结型狼人

先明确魅惑次数、目标合法性、是否可以连续选同人、持续多久、被魅惑者是否知情、哪些狼美人死亡触发连带，以及连带死亡是否禁技能。不能默认魅惑会禁票、使目标知情或让其必然配合。

| N | 优先选择 | 修正条件 |

| ≥9 | 隐藏身份，选择潜在关键目标，保留普通狼的配合计划 | 没有可靠具体身份信息时使用候选解释，不直接读取神职表 |
| 7～8 | 比较连结信息核心、防护者、关键票者与普通好人 | 目标下一夜可能正常死亡、连结失效或禁连选时及时换目标 |
| 6 | 展开自身出局连带与狼刀分支，判断是否能达到实际胜利条件 | 不能把“绑住神职”本身当作已经阻止其当轮技能 |

| 3 | 精确计算最后连结、有效票与对手反击 | 对方不知道连结时不能依赖公开威慑；知道也不代表会帮狼 |

| 7～8 | 比较保护情侣、帮助原阵营或推动第三方路线，计算一方死亡的连锁风险 | 恋人关系不自动改变阵营，只有规则确认后更新 |

## 11. 风格设计

风格与真实身份独立分配，局内相对稳定；策略根据局势切换。风格不授予额外信息，也不改变技能或阵营目标。

| 风格 | 判断与公开表达倾向 | 各身份的表现 |
| --- | --- | --- |
| 谨慎分析 | 比较解释、较晚披露、减少弱依据冒险 | 民重条件判断；预言家报结果与依据；女巫比较用药分支；猎人审查枪口；狼维护长期可信度 |
| 主动主导 | 较早站边、组织行动、争取关键票 | 民推动归票；预言家主动带队；女巫关键冲突中亮身份；猎人适时威慑；狼争夺解释权 |
| 隐藏试探 | 保留信息、提出条件问题、择机改变公开策略 | 民试探；预言家有条件隐藏；女巫隐藏药量；猎人藏枪；狼用分歧减少曝光 |

危险局面会提高所有风格的行动优先级。谨慎型在等待必输且仍有有效行动时也会选择目标；主动型仍需要依据。强势语气不等于神职，犹豫不等于平民。

## 12. 每张策略卡需要记录什么

| 字段 | 内容 |
| --- | --- |
| 编号与名称 | 稳定标识，便于引用与复盘 |
| 身份与阵营 | 真正可用身份；狼队战术分工另记 |
| 规则前提 | 胜利条件、技能、公开信息、沟通或发言窗口 |
| 人数索引 | 适用 N 范围；只是入口，不替代阵营与资源条件 |
| 局面条件 | W/G 候选、票权、资源、信息与阶段 |
| 触发与优先级 | 什么情况下采用，基础/常规/进阶的推荐地位 |
| 本轮目标 | 具体收益，如形成对某目标的集中票 |
| 行动 | 公开发言、实际投票、技能或队内计划 |
| 对手应对 | 反驳、对跳、救守、倒钩、绕枪等可能反应 |
| 修正与退出 | 哪种新信息改变目标，怎样结束或撤回 |
| 失败代价 | 错误放逐、误伤、身份暴露、资源耗尽、立即判负等 |
| 可观察结果 | 信息是否被传递、目标票是否集中、资源是否有效、计划是否兑现 |
| 示例与反例 | 正常适用例、缺失规则例、应退出例、对手反制例 |

### 12.1 完整卡示例：W04 危急用毒

- 真实身份：女巫；真实资源：毒药可用、解药不可用。
- 规则与夜间条件：两阵营人数胜利，狼刀已确定会杀死一名好人；同夜不能双药；被刀女巫仍可当夜用药；无有效保护、枪或连锁反击；夜晚完整结算后判胜。
- 人数入口：N=3；局面：已完成上次判胜且继续，推出 1 狼 2 好人。
- 触发：不行动会使次晨达到 1 狼 1 好人；仅用毒有机会阻止判负。
- 目标：毒死最后一狼，争取当夜结束游戏。
- 行动：依据真实结果、声明冲突与历史在合法未知候选中选择；即使自己被刀也检查是否可行动。
- 对手应对：狼可能伪装神职、利用旧站边取得信任，或攻击另一个好人。
- 修正：发现真实有效防护、自救资源、禁毒状态或不同结算时序时，退出本卡并重算。
- 失败代价：毒错好人即失去取胜机会；不以“这是猜测”为由回避仍可作出的决定。
- 风格差异：谨慎型更重视旧声明核对；主动型更快给出明确目标；均使用同一可见事实和风险条件。

### 12.2 反例

- N=3 但采用屠城或第三方规则，不能仅凭“游戏继续”推出普通 1 狼 2 好人局面。
- 解药仍可合法救人，应同时比较救人保留白天与毒人立即取胜，不自动选择赌毒。
- 已知守卫有效保护，或猎人可在完整结算中反击，应加入相应分支。
- 狼刀允许自刀或空刀，且不能确定本次会减员一名好人时，不直接断言“不用毒必输”。
- 仅听别人自称女巫有毒，不能把该声明作为自己实际可用资源。

## 13. 决策时如何使用策略库

1. 取得当局规则和玩家自己的可见状态，标明已完成与待结算阶段。
2. 根据硬事实推导可行局面；保留仍未确定的狼数、身份、资源和票数分支。
3. 用真实角色、N、规则与资源检索少量相关策略卡；保留基础判断卡。
4. 比较各行动的命中、误判、对手反击与下一轮分支。信息不足时选择当前依据最好的方案。
5. 确定本轮目标及一个有条件的备选；用风格影响公开表达、披露和冒险倾向。
6. 记录简短私有摘要：使用的打法、当前目标、哪些内容是说辞、何时切换。实际发生的公开声明仍以事件为准。
7. 投票前使用全部已出现的可见发言重新评估；夜间行动使用新的资源与人数状态。
8. 新事实出现后重算，避免把上轮计划当作不可更改的命令。

初期可以使用局内静态 Markdown/结构化策略内容进行条件检索，无需把全部角色攻略每次放入上下文。规则与合法行动由引擎提供，模型负责选择和表达；狼队共同计划需要独立的合法私有沟通语义。

## 14. 典型局面与设计验收

这是后续策略评估的场景清单，不要求每次取得最优结果，也不以事后真实身份直接给当时的 AI 输入提示。

| 场景 | 应能表现出的判断 | 典型错误 |
| --- | --- | --- |
| 12 人配置、只剩 7 人、可能仍有 3 狼 | 识别 3 狼 4 好人的危险分支 | 因人数较多就继续无限观察 |
| 5 人、两狼、三好人，统一最高票放逐 | 狼队计算集中票；好人比较可信目标并减少分票 | 两狼有票就声称必胜，忽略好人三票能集中 |
| 5 人、只剩一狼 | 保留独狼与倒钩解释，使用不同于双狼残局的节奏 | 机械沿用“错一票必输” |
| 放逐前确定 2 狼 3 好人，放逐后继续 | 推出出局者为狼 | 因不翻牌就认为完全无法推断 |
| 女巫知道真实银水被报查杀 | 无自刀规则下识别查验声明为假，考虑如何公开纠偏 | 把仅听来的银水声明当作确定事实 |
| 女巫有毒无解药，3 人继续的人数局 | 识别不行动后果，选有依据的毒口 | 无有效其他防护却永远等待铁证 |
| 猎人被放逐导致人数相等，枪尚待触发 | 按板子决定先枪后判胜或先判胜 | 用普通人数公式跳过技能窗口 |
| 猎人首夜无信息死亡，允许弃枪 | 比较弃枪与开枪的净收益 | 用“一定开枪/一定闷枪”跨板子处理 |
| 女巫有人对跳，但好人允许穿衣服 | 区分假身份与狼人阵营，综合判断 | 无条件毒死对跳者 |
| 仅公开总票数 | 分析票数约束与投票意向，承认未知个人票 | 编造某人已经投给谁 |
| 屠边局最后一张平民仍活着 | 识别该角色类别的胜负风险 | 只计算狼好总人数差 |
| 白痴翻牌免死失票 | 使用实际票权分析 | 把存活好人数全部当作可投票数 |
| 狼队刀带毒女巫或可开枪猎人 | 展开当夜反击或枪的可能后果 | 认为刀死即能阻止当轮技能 |
| 每人只有一次发言且无遗言 | 降低需要当天退水或死后解释的策略优先级 | 假跳后假设自己还会得到补充发言 |
| 第三方或情侣阵营 | 根据实际胜利条件展开连锁与阵营关系 | 把所有非狼一律当作己方 |

评估同时关注：规则适配、信息来源正确、危险识别、关键票配合、技能净收益、策略修正、风格差异，以及不同板子与座位下的胜负结果。胜率应结合样本、角色和对手强度观察；一次成功不能证明套路普遍有效。

## 15. 建设顺序

1. 建立规则参数、共同基础卡，以及五个核心身份的人数索引与策略卡。
2. 在当前 6 人规则下适配平民、狼人、女巫、预言家；同时保留猎人规则与卡的设计。
3. 扩展多人数配置与猎人时，先明确枪与判胜时序，再增加对应场景。
4. 扩展警长、守卫、白痴与特殊狼时，将本文矩阵绑定具体规则，补充板子专属交互卡与场景。
5. 用对局反馈调整策略优先级与触发条件，逐步增加有明确收益的进阶套路。

本文确定的是可扩展的策略组织与讨论内容。后续实现应建立单独的 OpenSpec 变更，明确规则扩展、策略检索、局内策略记忆和狼队沟通各自的范围。

## 16. 第一版运行方式

- 执行数据为 [strategy_library.json](../llm/strategy_library.json)，包含 67 条策略、10 类身份及每类七档人数指导。策略内容、阶段、规则前提、触发标签、优先级均在数据中维护；后续调整以执行数据为准并同步设计说明。
- [strategies.py](../llm/strategies.py)在每次行动前使用最新存活座位、真实角色和合法视角事件构建局面，检索最多 8 条策略；策略段上限 4000 字符，不额外调用模型。
- 共同基础卡始终保留。角色卡按阶段、明确规则及资源过滤，真实查杀、首夜、自身被刀、小人数和危险局面影响检索。指导给出调整条件，模型继续依据完整历史选择目标。
- 未知狼数保留候选；私有查验或刀口只服务合法接收者。当前固定六人规则允许推断单名夜间死者为好人，这一能力需要在规则配置中明确声明，未来存在守护、其他死因或阵营变化时不能直接沿用。
- 库作为包数据发布并在进程内缓存；修改后重启生效。数据缺失或校验失败时使用基础参考，保持原有 JSON 响应、校验、重试与对局流程。
- 当前五个请求接入的是六人规则配置。猎人等未来策略数据可用显式规则配置检索；实际玩法还需要扩展引擎、决策入口和对应判胜时序，策略文件不会自动增加技能。
- 对应实现变更：[add-runtime-ai-strategy-library](../openspec/changes/add-runtime-ai-strategy-library/proposal.md)。离线检查验证条件筛选与请求接入，真实策略效果需要在真实对局中观察。
