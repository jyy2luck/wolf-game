# 上下文与请求预算验证

2026-10-15，本机 `api.deepseek.com` / `deepseek-flash`。所有真实请求强制关闭思考，基础输出预算 4096、上限 16384；输入软预算 12000、行动总时限 90 秒。未配置模型窗口，不将应用预算当作服务的模型规格。没有修改本机密钥文件。

## 行为与检查

- 完整事件保留在引擎中；角色策略推导、引用与事实校验继续读取完整可见记录。
- 超预算时省略重复板子/阶段标签，保留真实事实、最新狼队主观计划、带编号的旧发言节选，并优先保留最近六条原文。极小预算下近期原文条数也会减少。节选中的身份和查验仍是玩家声明。
- 支持按编号回查最多三条公开原文，每行动最多一次；回查、网络、格式/事实纠正及截断共用三次实际请求和同一个总时限。
- 流式持续返回数据仍会在总时限到达时取消；鉴权等不可重试错误立即停止。截断扩容仅作用于当前行动。
- 请求日志/公开记录包含估算与实际输入、输出/思考/缓存 tokens、耗时、请求错误和响应校验分类，不包含密钥、完整提示词、私有策略或失败候选。

合成 120 条长发言用例中，估算输入从 39067 降至 11997 tokens，原始 124 条事件全部保留。这是固定测试数据的输入估算，不是实测费用节省率。

离线验证：535 项测试通过，OpenSpec 严格校验及 `git diff --check` 通过。四种板子、种子 42/43 共 8 局全 AI 离线对局全部结束，降级为 0。测试还覆盖 120 条历史的全部行动路径、视角隔离、回查后真实/伪造引用、模型窗口预留、混合错误最多三次请求、流式滴流取消、跨请求共享总时限和错误正文不进入指标。

## 结果的解释与限制

请求 `result=ok` 只代表 API 完整返回，最终是否接受由 `validation` 标记决定。仍可能因引用编号、发言人、天数、原文不匹配，或缺少 references 而重试/降级；关闭思考和控制上下文不能保证模型每次都满足事实约束。

当前只核查预算与响应耗时，没有运行启用深度思考的对照组，不能据此量化相对旧版本的提速、节费或胜率变化。真实对局结果和次数会随模型输出、网络及服务负载变化；独立对局曾同时运行，每局内部保持串行。

输入 token 数使用无依赖的偏保守估算，并在服务实际 usage 大于估算时向上校准；没有通用精确分词或自动发现模型窗口。固定事实和当前任务本身超过预算时仍会明确安全降级，不能保证任意长局永不触发。旧发言是程序节选，未额外调用摘要模型；真实对局未主动触发原文回查，回查流程由确定性测试验证。

## 复现与诊断

```bash
uv run pytest
openspec validate bound-game-context-and-generation --strict
uv run python scripts/benchmark_games.py --boards six-classic nine-standard twelve-standard --seeds 42 --output /tmp/wolf-new-run
uv run python scripts/benchmark_games.py --mock --boards six-classic nine-standard twelve-standard twelve-guard --seeds 42 43 --output /tmp/wolf-new-offline
```

输出文件不会覆盖，每次使用新目录。`summary.json` 记录终局状态、请求次数、p50/p95/最大耗时及分原因统计；最多 10 天后标记 `max_days`，不会伪造完成。

正常游戏中的压缩日志会显示压缩前后估算与预算，逐请求指标中的 `input_limit` 是实际采用的输入上限。`output_truncated` 表示输出截断，`input_context` 表示服务拒绝上下文，`action_timeout` 表示行动总时限到达，`validation` 中的错误表示生成内容未通过校验。`--record` 可把请求指标与公开对局一起保存。
