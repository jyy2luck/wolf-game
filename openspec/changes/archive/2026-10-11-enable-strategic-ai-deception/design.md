## Context

动机与行为边界见 `proposal.md` 和 `specs/ai-players/spec.md`。

现有实现已经提供角色视角过滤、完整可见事件、真实发言编号和统一重试管道。主要冲突在于 `detect_leak` 按真实角色拦截查验、用药、自认狼人等语句，提示词也要求狼人绝不认狼；`SpeechPack.suspect` 又被保存为 `last_suspect` 并作为当前怀疑对象回灌，没有明确区分公开立场和内部判断。

公开事件由引擎写入，正式发言生成期间的原始 JSON 不展示。这让私有策略能够复用已有结构化请求和玩家对象，无需新增事件类型、界面或请求阶段。

## Goals / Non-Goals

**Goals:**

- 让已确认的欺骗边界在提示词、校验和后续决策中保持一致。
- 用最少的局内状态记住真实判断与对外说辞，所有真实事实仍来自原有视角事件。
- 保持公开记录核对、单次发言请求和统一的失败处理路径。

**Non-Goals:**

- 不建立心理模型服务、逐步推理日志、完整谎言数据库或跨局长期记忆。
- 不新增独立规划或审核模型调用，不通过模型深度思考开关实现规则调整。
- 不自动评判策略是否最优，不修改胜负、技能权限、票型公开方式或六人局配置。

## Decisions

### D1. 真实事实始终来自视角事件，策略摘要只表示主观判断

继续从 `visible_events` 的结果渲染全部可见历史，并保持系统公开事实、角色私有事实和玩家声明的来源标签。真实身份、狼队友、实际查验和用药结果只从角色配置与可见事件取得；不把模型生成的摘要合并进事实事件。

在情境层另设“你的私有策略摘要”，明确它包含可修正判断和公开说辞。提示词要求按“可见事实 → 局势判断 → 本轮目标 → 对外表达”组织决策；遇到新真实事件与旧判断冲突时，以事件为准。“我是预言家”“我验了3号”等自己过去的发言只证明说过这句话。

备选：复制一份模型生成的“真实事实清单”再长期维护，会产生与事件流竞争的事实来源，因此不采用。

### D2. 在同一发言包中加入一个可选的简短策略摘要

在 `SpeechPack` 增加可选 `private_strategy`，包含 `assessment`（当前判断）、`goal`（本轮目标）和 `claim`（计划维持或调整的公开说辞）三个短字符串，分别限制为 120、60、120 字。只要求决策摘要，不要求详细思考过程。JSON 示例明确区分这些私有字段与公开 `speech`。

`suspect` 继续保留现有字段名和取值约束，但语义明确为公开声称的怀疑对象；`last_suspect` 如继续使用原名，也须在上下文中标为“上轮公开怀疑对象”，不得标成真实判断。不再添加第二个真实怀疑座位字段，内部判断放在摘要中即可表达“知道3号是好人，但准备攻击3号”。

省略或为 null 的 `private_strategy` 表示本轮没有新摘要，保留此前已接受摘要，兼容旧包和离线返回；如果提供摘要，按有界字符串结构校验。人物语气只影响公开表达，不替代真实阵营目标。

备选：先请求完整策略再单独请求发言，会增加延迟与失败点；每轮保存大段思考也没有必要，因此采用同包短摘要。

### D3. 仅在最终校验成功后提交私有策略

每个 `AIPlayer` 保存最新已接受的 `private_strategy`；公开历史继续负责保留历次实际说辞。最终候选经格式、目标及公开记录校验后，才一起更新公开怀疑对象和私有摘要。拒绝候选不得修改玩家状态。

重试耗尽时仍公开中性兜底并清空当前公开怀疑倾向，但保留此前已接受的策略摘要。下一轮看到的真实事件仍包含这次兜底，不会将旧计划误标为本次实际发言。

后续发言、投票、预言家行动、女巫行动与狼窝调用都带上调用者自己的最新策略摘要。狼窝共享会话继续沿用现有调用者和角色视角，不额外读取另一个玩家对象的私有摘要。新局新建玩家对象自然清空策略。

备选：新增私有策略事件流或保存每次完整摘要，会重复现有公开历史与局内状态，本次不采用。

### D4. 删除按身份表演关键词拒绝发言的路径

删除 `LEAK_WOLF_ID`、`LEAK_TEAMMATE`、`LEAK_CHECK`、`LEAK_POTION` 所代表的限制，以及发言管道中对应的泄密计数和特殊重试分支。按实际调用关系清理不再使用的检测入口，不保留永远返回通过的空检测器。

提示词取消“狼人绝不认狼”“不能提队友或刀口”“真实身份绝密且只能终局公开”等约束，改为明确：真实身份决定目标和权限，公开身份可以表演；已知私有信息可以选择披露，不知道的私有结果可以猜测或编造。声明中的技能不会赋予实际技能权限。

视角隔离仍在输入构建处执行。不使用全知角色表、其他玩家的私有结果或隐藏真相核验发言是否“太准”，也不把真实角色与声明不符当违规。这样允许策略性自认身份，也允许普通失言产生真实博弈后果。

备选：仅为狼人放开“我验过”，仍会限制已确认的好人假跳与全角色认狼，且继续混淆声明和权限，因此不采用。

### D5. 公共行为核对保留，动机与身份判断不作真实性审核

继续使用 `references` 与原始发言索引核对来源、人物、时间和直接引语。真实短片段可选择性引用，不要求复述全文；对动机的解释和身份判断即使片面、武断或错误，也不据此拒绝。

在现有有限中文行为规则中补充用户明确指出的“长篇大论、一直辩解”等无记录行为，以及“眼神躲闪、拍桌子”等当前文字输入不存在的观察依据。对直接与公开死亡或票数事件冲突的已覆盖断言，以同一可见事件流核对，不引入另一份全知信息。识别行为主体、否定、条件、未来及引用范围，避免把“等2号发言”“他声称2号抢话，我不信”误判为本人陈述。

自身身份、查验、用药等私有经历声明不套用“他人公开行为必须有记录”的要求。其对外说辞允许与自身真实行动不符，但不改变实际事件。给“我觉得2号刚才长篇大论”加上主观前缀，也不能把不存在的公开行为变成允许的推测。

自然语言核对只覆盖高置信度、可解释的冲突；提示词约束其余表达，不声称正则能够验证任意中文语义。拒绝原因仍只反馈具体公开记录冲突。

备选：全量删除事实校验会重新引入原问题；新增语义审核模型增加请求成本且不能保证正确，因此均不采用。

### D6. 私有摘要沿用已有缓冲和展示边界

正式事件与 AI 发言方法的公开返回值仍只包含发言、公开怀疑对象和情绪，不携带摘要。引用依据和策略摘要留在调用内部，候选原始 JSON 不传给终端逐字回调，也不在常规面向玩家的错误信息中打印摘要值。

发言、投票和夜间行动的目标合法性仍由现有校验及引擎决定；一次发言共享首次加最多两次重试，摘要格式问题不引入额外循环。更新提示词示例、离线 mock 与文档，让“允许身份表演”和“私有策略不展示”具有一致含义。

## Risks / Trade-offs

- [私有摘要仍可能包含错误判断] → 始终标为可修正的主观策略，真实事件独立提供，禁止摘要生成真实技能事件。
- [放开伪装后策略可能失败或偶发暴露身份] → 保留真实阵营目标与连贯性提示，允许博弈失败，不用关键词替 AI 决定战术。
- [中文行为规则漏检或误伤] → 针对无记录行为、假引用、条件假设和反驳转述成对验证，明确有限覆盖范围。
- [新增字段占用输出预算] → 三个短字符串使用现有单次请求、输出预算和截断扩容，不强制旧包补齐摘要。
- [摘要与最终公开内容不一致] → 摘要只随成功候选提交，实际说过什么始终以最终公开事件为准。

## Migration Plan

1. 更新提示词、发言包与玩家局内状态，调整发言校验路径和所有决策调用的摘要上下文。
2. 更新原有防穿帮用例为允许伪装与输入隔离用例，增加策略跨轮次、失败候选不提交及公开记录正反例验证。
3. 修订 README 的行为说明，执行针对性校验和现有回归测试。
4. 归档前同步 `ai-players` 增量规范。此次只增加局内内存状态，无持久数据迁移；回退代码并开启新局即可恢复旧行为。
