# Spec Delta

## ADDED Requirements

### Requirement: 启动板子选择
未指定 `--board` 启动时，终端 SHALL 在配置引导、角色分配和模型请求前要求玩家选择板子，展示原六人局、九人预女猎、十二人预女猎白、十二人预女猎守的编号、人数、角色配置和警长开关。菜单 SHALL 接受合法编号，回车默认六人局，拒绝非法输入并要求重选。选定后 SHALL 按该板子建局；显式 `--board` SHALL 跳过菜单，未知板子仍由命令行参数校验拒绝。

#### Scenario: 普通启动
- **WHEN** 玩家未传 `--board` 启动，包括离线模式
- **THEN** 先显示四种玩法的选择菜单，两种十二人局可通过白痴与守卫配置区分

#### Scenario: 选择九人或十二人板子
- **WHEN** 玩家输入九人局或任一十二人局对应编号
- **THEN** 按所选板子的实际人数、角色与警长规则创建游戏，角色卡及记录采用同一板子

#### Scenario: 保留六人默认
- **WHEN** 玩家在菜单直接回车
- **THEN** 使用原六人局，固定种子时分配结果与显式指定 six-classic 一致

#### Scenario: 非法输入
- **WHEN** 玩家输入越界编号、负数或非编号文本
- **THEN** 提示合法编号并继续等待选择，不进入配置、不建局、不调用模型

#### Scenario: 显式指定板子
- **WHEN** 玩家传入合法 `--board`，同时可传入 --mock、--seed 或 --record
- **THEN** 跳过菜单并使用指定板子，其余参数保持原有含义

#### Scenario: 未知板子参数
- **WHEN** 玩家传入未注册的 --board 值
- **THEN** 显示参数错误与可用值，不显示菜单或发送模型请求

### Requirement: 选择期间安全退出
菜单输入期间发生 Ctrl-C 或输入结束时，系统 SHALL 提示已退出并以状态码 130 结束，不进入配置引导、不创建对局或发起模型请求；已有配置和对局记录 SHALL 保留。

#### Scenario: 中断选择
- **WHEN** 玩家尚未选定板子就按 Ctrl-C
- **THEN** 安全退出，显示退出提示，已有配置和记录不被修改

#### Scenario: 菜单输入结束
- **WHEN** 尚未选定板子时标准输入结束
- **THEN** 安全退出，不把输入结束显示为游戏故障或自动开始默认对局
