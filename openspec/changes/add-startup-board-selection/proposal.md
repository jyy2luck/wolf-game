# Proposal

## Why

引擎已经支持九人局与两种十二人局，但普通启动默认进入六人局，玩家需要知道命令行参数才能体验其他玩法。启动时提供明确的板子选择，让所有已支持玩法可直接发现和进入。

## What Changes

- 未指定 `--board` 时，在配置加载和建局前展示游戏选择菜单：原六人局、九人预女猎、十二人预女猎白、十二人预女猎守。
- 每项展示人数、角色配置和警长开关；输入编号选择，回车默认六人局，非法输入提示重选，中断或输入结束安全退出。
- 保留 `--board` 直接指定板子并跳过菜单，沿用现有引擎规则、AI、终局统计和记录格式。
- **BREAKING**：未传 `--board` 的启动新增一次输入；脚本需显式指定 `--board`，避免原有输入错位。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `terminal-ui`：新增启动板子选择与输入校验要求。
- `config-management`：已有配置在板子确定后自动加载；重新配置同样在选择后执行。

## Impact

- 修改 `main.py` 参数默认值与启动顺序、`ui/terminal.py` 菜单，复用 `engine.boards.BOARDS` 注册表。
- 更新入口相关测试、夹具与 README 启动说明，增加所有板子的菜单接线和退出验证。
- 无新依赖，不改板子定义、配置文件、存档格式或既有游戏规则。
