# Spec Delta

## ADDED Requirements

### Requirement: 回应与个人票型展示
终端 SHALL 明确提示人类当前是首轮发言或简短回应，展示统一投票结束后的个人目标和弃票。狼队共享计划 SHALL 仅向人类狼人展示；好人终端 MUST NOT 展示该计划或 AI 个人摘要。

#### Scenario: 人类回应
- **WHEN** 轮到人类进入回应轮
- **THEN** 界面提示回应关键指控并说明这是投票前的最后发言机会

### Requirement: 公开对局记录与生成统计
终局 SHALL 展示结构化请求重试及降级次数。用户指定记录路径时 SHALL 保存公开正式事件、座位姓名、随机种子、模型名称和生成统计；MUST NOT 保存 API 密钥、角色私有事件、私有摘要或失败候选。记录 MUST NOT 覆盖已有文件，写入失败 SHALL 提示原因而不改变对局结果。

#### Scenario: 保存公开记录
- **WHEN** 用户指定一个不存在的记录文件并完成对局
- **THEN** 文件包含两轮正式发言及公开个人票型，可核对关键行动和重复发言

#### Scenario: 私有内容不落盘
- **WHEN** 对局含查验、用药和狼队计划等私有事件
- **THEN** 公开记录排除这些事件和所有个人私有摘要

#### Scenario: 记录路径已存在
- **WHEN** 用户指定的记录文件已存在
- **THEN** 保留原文件内容并提示保存失败
