# 🐺 LLM 狼人杀（llm_murder）

终端单机狼人杀：**1 名人类玩家 + 5 个 LLM 玩家**的 6 人局。打开终端即可开局，AI 玩家有性格人设，会依据可见信息判断局势，也能假跳身份、试探和误导其他玩家。

- 规则判定 100% 由确定性引擎完成，LLM 只负责「表演」（发言、投票、技能决策）
- 玩家与 AI 共用同一套视角隔离机制，信息绝对公平
- 6 人局固定配置：狼人 ×2、预言家 ×1、女巫 ×1、平民 ×2（第一版无警长）

## 安装

需要 Python ≥ 3.11。推荐使用 [uv](https://docs.astral.sh/uv/)：

```bash
uv sync            # 创建虚拟环境并安装依赖
```

或使用 pip：

```bash
python -m venv .venv && source .venv/bin/activate
pip install openai rich pydantic pytest
```

## 配置

首次启动会进入交互式引导，依次填写 OpenAI 兼容配置：

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| base_url | `https://api.deepseek.com/v1` | 任何 OpenAI 兼容服务（DeepSeek / Qwen / OpenAI 等） |
| api_key | — | 输入不回显；自备 |
| model | `deepseek-chat` | 可修改 |

- 配置写入前会发起一次最小连通性请求验证，**通过才落盘**
- 配置保存到 `~/.llm_murder/config.json`，权限强制 600，绝不写入项目目录
- 之后启动自动加载；`--reconfig` 可重新配置

旧配置无需修改，重启即采用新的生成预算。可在 `~/.llm_murder/config.json` 中增加以下可选字段：

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| max_tokens | `4096` | 单次输出预算，包含模型思考与最终答案 |
| max_tokens_limit | `16384` | 截断后扩大预算的上限，不能小于 max_tokens |
| thinking | `null` | DeepSeek 官方服务默认关闭深度思考，其他服务遵循服务默认值；可显式设为 `"enabled"` 或 `"disabled"` |
| json_mode | `null` | DeepSeek 官方服务自动启用 JSON 模式，其他服务默认不启用；可显式设为 `true` 或 `false` |

DeepSeek Flash 服务默认会进行高强度思考，可能在输出投票 JSON 前消耗数千 tokens。游戏默认明确关闭 DeepSeek 深度思考，以降低等待时间和输出截断；旧配置无需重配。需要启用思考时可设置 `"thinking": "enabled"`，此时仍可能触发预算扩容。输出预算必须为正整数，终局统计会单独显示其中的思考用量。

## 运行

```bash
uv run python main.py             # 正常启动（无配置则引导）
uv run python main.py --reconfig  # 重新配置 LLM 连接
uv run python main.py --mock      # 离线演示模式（不调用真实 LLM，验证流程）
uv run python main.py --seed 42   # 固定随机种子（复现对局）
```

玩法：

1. 开局随机分配角色，展示你的角色卡与 6 人座位表
2. 夜晚：狼人确认刀口（狼人可选委托 AI 队友）→ 预言家查验 → 女巫用药（解药/毒药各限一次、同夜不同用）
3. 白天：按座位顺序发言（从上一位死者下家开始）→ 统一投票 → 得票最高者放逐（平票无人出局）
4. 胜负：狼人全部出局 = 好人胜；存活狼人数 ≥ 存活好人数 = 狼人胜

输入约定：白天发言为多行输入（单独回车结束）；技能与投票为受限选项输入（非法输入拒绝重输）。
终端支持中文行编辑；若输入含无法解码的字符，会提示重输当前行，保留此前已输入的发言行。

发言顺序由引擎统一提供给 AI：例如 5 号死亡后，当天顺序是 6、1、2、3、4。
6 号首位发言时，已发言集合为空，1、2、3、4 号尚未轮到；轮到 1 号时，6 号已完成，2、3、4 号仍在等待。
“尚未轮到”只描述今天的流程，不能据此指控玩家故意沉默，也不表示他在往日没有发言。
平安夜沿用既有起点，无既往死者时从 1 号开始；有既往放逐则沿用其下家，多名夜间死者时以首位死者为起点。

AI 的发言、投票和夜间行动都能读取本局截至当前的全部可见历史，包括人类和 AI 的公开发言。
每条记忆标明天数、昼夜与来源（系统公开事实、角色私有事实或玩家声明）；已出局玩家的发言仍保留。
例如第 2 天可引用“第 1 天 2 号在 [#3] 说过……”；2 号今天尚未轮到不影响这个真实历史编号的有效性。
自身最近三条发言摘要只辅助保持立场，完整历史仍在；新局重新创建事件和 AI 状态，私有信息继续按角色视角隔离。
玩家说过某句话只证明其声明存在，不证明句中指控属实；总得票数也不能证明其他玩家各自投给了谁。

所有角色都可以假装其他身份或阵营、假认狼、编造自己的查验与用药经历，以帮助真实阵营获胜。
可以选择性引用真实发言、夸大嫌疑或歪曲动机；不能伪造原话、编造他人的公开行为，或把正常轮候说成故意沉默。
例如“我是预言家，昨晚验了3号”可以是骗局；但2号整局尚未发言时，说“2号刚才长篇大论”会被拦截。
AI 会用同一次发言请求生成简短私有策略摘要，区分真实判断、本轮目标和公开说辞，供后续发言、投票与夜间行动参考。
摘要是可修正的主观策略，不能替代真实事件；投票可以不同于公开攻击对象，假跳也不会获得真实技能权限。
摘要按玩家和对局隔离，只有调用者自己可用；允许策略失败，不要求每轮撒谎或每步最优。

AI 生成和重试期间显示发言人及“生成与校验中”状态；通过格式、目标和事实校验后，
由正式事件一次展示带 `[#编号]` 的完整正文。候选发言、原始 JSON、`references` 和 `private_strategy` 不展示给玩家。
失败时同样结束等待，按正式事件展示中性兜底，然后继续发言和投票。

## 单局成本预估

一局约 **60~100 次 LLM 调用**（夜晚技能 3~5 次 + 每个白天 6 次发言 + 6 次投票），调用基本串行，单局约 **10~20 分钟**。以 DeepSeek 为例，单局成本通常在 **几分钱人民币** 量级。终局会显示本次对局的调用次数与 token 用量。

## 项目结构

```
llm_murder/
├── main.py            # 入口 + 决策路由控制器（人类 UI / AI agents）
├── config.py          # LLM 配置：引导、验证、600 权限持久化
├── engine/            # 确定性引擎（全知、零 LLM 依赖）
│   ├── roles.py       # 角色枚举、6 人局配置、技能时序
│   ├── events.py      # 事件溯源 + visible_events() 视角过滤纯函数
│   └── game.py        # 状态机：昼夜循环、技能结算、计票、胜负
├── llm/
│   ├── client.py      # OpenAI 兼容客户端（流式/重试/用量统计/mock）
│   ├── agents.py      # 人设卡、四层 prompt、结构化解析、私有策略
│   └── grounding.py   # 原始发言引用与有限公开行为校验
├── ui/
│   └── terminal.py    # rich 渲染与玩家输入
└── tests/             # pytest：引擎、提示词、引用校验、客户端与终端集成回归
```

## 测试

```bash
uv run pytest
```

覆盖：角色分配、夜晚结算各分支（救刀/毒杀/空刀）、计票与平票、全部胜负条件、
视角隔离不变量（任何角色视角不含越权私有事件）、解析重试与降级、策略性欺骗、局内私有记忆与公开记录核对。

## 设计要点

- **事件溯源**：对局一切信息以事件流表示，玩家「记忆」= 视角过滤后的子集（纯函数），人类与 AI 同机制
- **发言依据**：发言包的 `references` 提供真实发言编号、座位、天数与原文片段，正文使用对应 `[#n]`。系统同时核对依据与正文，允许跨天及已出局玩家引用；旧包缺少字段按空列表处理，无引用发言仍需接受事实校验
- **表达策略与事实边界**：真实身份只决定阵营目标和技能权限，公开身份、自己的私有经历和动机解释可以是策略性说辞。检查明确的无记录行为、时间错置、不可见表情动作及死亡、得票断言的直接冲突；保留等待、条件假设、主观怀疑与有真实依据的反驳转述。自然语言检查只覆盖明确句式，不能证明任意转述或推理都正确
- **私有策略**：发言包可包含 `private_strategy`（assessment 当前判断、goal 本轮目标、claim 公开说辞，分别最多120、60、120字）。`suspect` 表示公开怀疑对象，不等于真实判断。摘要只在最终发言通过校验后更新，旧包省略或填 null 时保留此前摘要，新局清空
- **有界纠正**：发言格式、目标、事实、摘要格式和截断共享首次加最多两次重试。截断（`finish_reason=length`）在现有 token 上限内扩容，客户端网络重试仍单独处理。最终失败只使用“目前依据不足，我暂时保留判断。”，公开怀疑未定、情绪平静；失败候选不更新私有策略，此前已接受摘要仍保留。投票与技能仍有安全降级
- **狼窝合议**：两狼共享一次调用统一刀口，省调用且保证一致
